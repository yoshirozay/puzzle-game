# The Lounge — feature brief and build instructions

Self-contained handoff for a fresh session. Read this top to bottom before
writing code; almost all the infrastructure already exists.

## The idea

The app's meta-game. Players earn **points** by playing the six puzzle games
(already wired: Tiki Stacks pays `max(1, score / 10)` points per run into a
persistent wallet via the game-agnostic `recordRun`; the other games join as
they gain gameplay). They spend points in **the lounge** — a mid-century tiki bar interior
that starts nearly empty and fills with life as items are purchased: decor,
drinks, patrons, and eventually the suspicious cat. The lounge is the reason
to keep playing all six games, and the app's emotional home.

Design north star: mid-century flat-vector tradition (Charley Harper, Jim
Flora, Mary Blair) — flat fills, hard geometric shadows, angular silhouettes,
saturated-but-economic palette, sentence of
mystery in every scene. No gradients, no blurs, no soft shadows.

  `xcrun simctl io <sim> screenshot /tmp/x.png`. Create a sim if none exists
  (`xcrun simctl create ... iPhone-17 iOS-26-3`, then boot).

  that got every scene to A+.

## Hard-won gotchas (each of these cost a debugging round — respect them)

1. **Xcode's SVG importer ignores `fill-opacity`** (and `<text>`). Any
   transparency must be applied in SwiftUI (shape fills with `.opacity`,
   or mask the image — see `BoardFrameHole` in TikiStacksView.swift).
2. **Swift type-checker**: inside Canvas closures annotate every value with
   explicit `Double` and never mix CGFloat/Double in one expression —
   otherwise "unable to type-check in reasonable time".
3. **Don't hold view session state in `@State` written from escaping
   closures** — a stale view identity can swallow the write. Put it on the
   @Observable model (see `lastRunSummary` on TikiStacksGame).
4. **Colors**: use the mode-stable scene palette (`P.*` in TikiScenery.swift)
   for anything drawn over scenes. Asset-catalog colors flip in dark mode.
5. ViewBuilder closures can't do deferred `let` initialization — compute in
   helper funcs.
6. Piece/scene layout is proportional to screen size everywhere; follow that.

## Economy notes (current placeholder values — tune freely)

- Earn: `max(1, score/10)` per run. A decent Tiki Stacks run ≈ 100–450 score
  → 10–45 points. Catalog spans 50 (mug) to 500 (cat), 13 items totaling
  2,880 — the mug is priced so the first purchase lands inside the first
  session. The cat should stay the endgame flex; keep new items below 500.
  Tuning is safe post-launch: the catalog syncs as an upsert every launch.
- `RunSummary` (returned by `recordRun`) already reports pointsEarned and is
  shown on the game-over panel ("+N POINTS" in gold).
